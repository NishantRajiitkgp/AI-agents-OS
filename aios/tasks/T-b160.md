## Context

`task.md` was a bootstrap: a hand-written plan for building the thing that was supposed to
replace it. Keeping it past that point makes two sources of truth about what is being worked
on, one of which is a markdown checklist that nothing validates and nobody can query — exactly
the shape `STATE-2` refuses, where progress is asserted by a tick rather than computed from
state.

Retiring it needed four requirement areas that had never been written. The M2, M4 and M6 work
was argued in `docs/design/` and recorded as decisions, but never stated as things the system
must guarantee, so every migrated task would have had to name a requirement that did not
exist. `guard.md`, `invocation.md`, `adapters.md` and `trial.md` close that, and `T-a141`
named the invocation gap explicitly on its way out.

The last verify command is the one that matters. Without it, migrating nothing and leaving the
file in place would satisfy this task.
